# BSides-Peoria-Badge-26
The badge schematic and board design for the BSides Peoria. Super cool thing I got to do.

## Technical Details and notes for nerds

I spent around a month and a half working on this badge, not because of procrastination, but that's when I found out I was doing it. I had some experience designing electronics projects before (see [Technet8394/HackTheBadge](https://github.com/Technet8394/HackTheBadge)) but had never designed a PCB before. I ended up throwing myself off the deep end with this one.

I have put a picture of the board programmer I fabricated in an hour using Pogo pins and JST Jumper wiring, (side note, yes I did solder directly to the ends of said jumper wires). It ended up working perfectly on every single one of the 300 boards I programmed. Unboxing, programming and repackaging actually only took an hour and a half. The programming script was lost due to my WSL instance destroying its virtual disk beyond repair. Which is wildly unfortunate, but beyond my control. 

The board was made with love in KiCAD, gotta love KiCAD, anywho if you have any questions DM me at technet.1337 on signal.
